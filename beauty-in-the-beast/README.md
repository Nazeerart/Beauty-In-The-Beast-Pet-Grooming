# Beauty in the Beast Pet Grooming Parlour — Website

Independent React + Vite site. No backend, no env variables.

## Run
    npm install
    npm run dev       # http://localhost:5173
    npm run build
    npm run preview

## Edit
- Phone, links, images: `src/config.js`
- Services & text: `src/App.jsx`
- Colours & layout: `src/styles.css`

## Images
The images in `src/config.js` are temporary generic stock photos, NOT photos of
the business. Replace them with the owner's own photos (put files in `public/images/`
and reference as `/images/yourfile.jpg`).

## Deploy
Push to GitHub, import the repo in Vercel (framework: Vite). Done.
