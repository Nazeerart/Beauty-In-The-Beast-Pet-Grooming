# Beauty in the Beast Pet Grooming Parlour

Responsive React + Vite website for Beauty in the Beast Pet Grooming Parlour in Uppal, Hyderabad.

## Features
- Colourful, professional design (pink / blue / sunny-yellow palette) that is fully responsive
- Sticky Call + WhatsApp bar at the bottom of the screen on mobile and tablet
- Floating Call + WhatsApp buttons on desktop, plus Call/WhatsApp buttons in the header
- Pop-up scroll animations, animated stat counters and scroll progress bar
- Photo gallery (masonry) with a pop-up lightbox: tap a photo, swipe or use arrow keys
- Video gallery with poster thumbnails, hover preview and a pop-up video player
- Embedded Google Map with address and directions
- Responsive layout for desktop and mobile
- Real salon pet photos stored locally in `public/images`
- Short pet-care videos stored locally in `public/videos` (thumbnails in `public/posters`)
- WhatsApp enquiry and booking links
- Click-to-call phone link
- Google Maps directions
- Services, gallery, reviews link, and contact sections
- Vercel configuration for Vite

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment
```bash
npm run build
npm run preview
```

## Deploy with GitHub and Vercel
1. Extract the ZIP.
2. Open the inner `beauty-in-the-beast` project folder in VS Code.
3. Test with `npm install` and `npm run dev`.
4. Commit and push the updated project to the GitHub repository connected to Vercel.
5. Vercel should build and deploy automatically if Git integration is enabled for that repository and branch.

The site uses local media files; no Google Drive login is needed for the gallery.
